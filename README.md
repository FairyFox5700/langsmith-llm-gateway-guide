# LangSmith LLM Gateway — Detailed Guide

A 22-page, prioritized guide to understanding and implementing the LangSmith LLM Gateway.

## Download

[Download the detailed PDF guide](./langsmith-llm-gateway-detailed-guide.pdf)

## Covered topics

- Gateway mental model and product boundaries
- End-to-end request lifecycle
- Authentication, provider credentials, and RBAC
- API formats, model IDs, routing, and translation
- First-call hands-on lab
- Tracing, observability, and access control
- Spend, rate-limit, model-access, and data policies
- Sensitive-data redaction behavior and security boundaries
- Model fallbacks and resilience design
- Custom model configurations and direct model access
- Cloud, BYOC, and self-hosted deployment patterns
- Production architecture patterns
- Troubleshooting and rollout checklists
- A 90-minute fast-study plan

## Intended audience

Engineers, solution architects, platform teams, and technical leaders evaluating or implementing the LangSmith LLM Gateway.

## Source and currency

The guide is based on the official [LangChain LLM Gateway documentation](https://docs.langchain.com/langsmith/llm-gateway). The Gateway is documented as beta. Confirm current availability, entitlements, model names, pricing, and behavior in the live documentation before making production decisions.
